# Painted cladding experiment — withheld from promotion

The source authoring and native parameter admission worked, but this experiment
does **not** resolve the approved-reference visual mismatch. It remains local
and separate from uploaded upper-receiver checkpoint `7a3b1fe`.

The saved study master forks `e027b3e5`. It changes only metallic/roughness inputs
for nine midnight-cladding source materials across owners141,160 and162, using
metallic0 and roughness0.46 as a painted-panel comparison. No base colors,
emission, glass/alloy profiles, mesh/UV/normal, object transforms, visibility,
material links or geometry slots change. Saved/reopened object signatures cover
47,101 objects. The first author's comparison mistakenly converted tuple links
to lists through JSON; the corrected comparison preserves data types and passes.
The first failed script/log remain under `output/local-scratch/v02-upper/`.

The separate candidate `SIGHTLINE_SAINT_MERIDIAN_V02_PAINTED_CLADDING_STUDY.html`
admits those source values only after validating all owner/palette/parameter
matches. Six cloned geometries prevent mutation of shared source buffers.
63,468 matched full/LOD vertices receive the new reflectance values. Native
before/after checks preserve all310owners' other attributes, indices, groups,
materials, transforms and compound boxes. Fixed A/B images and a short installed
skill-client movement capture were reviewed; no runtime errors were reported.

**Visual review: insufficient.** The sharp pale highlight becomes broader and
the facades read flatter/lighter in places. Changing reflectance alone does not
create articulated architecture, occupied terraces, motivated illumination or
the reference's canyon composition. This is not an accepted visual repair and
has not replaced either the uploaded checkpoint or default game entry.

Next source work should address actual facade relief and the warm direct-light
response together, beginning with source-identified building141 cladding. Use
existing window/reveal positions and original-owner destruction metadata, keep
the proven circulation/physical anchors clear, and compare unchanged A/B camera
bookmarks. Do not darken the whole game or reframe the camera to hide the gap.

The study still needs independent source rendering, broad gameplay/destruction
and sustained performance validation if any derivative is proposed for shipping.
Its current geometry/parameter checks do not establish those gates.
